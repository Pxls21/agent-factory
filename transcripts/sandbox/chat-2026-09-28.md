**Strata can't run lanes in parallel, and it can't run inside vLLM.** It might be faster for one lane at a time, but only a test on your PC will show that.

- **It needs the whole 3090.** vLLM holds 96% of the card now. Running Strata means stopping the qwen container for a window.
- **It is its own engine,** built from llama.cpp parts plus custom GPU code. vLLM can't load it.
- **Its 3090 speed is an estimate, not a test.** The author guesses about 100-140 tokens/s, but that guess assumes a newer CPU with faster memory (DDR5). Your PC has a Ryzen 5 5600X with DDR4, so the half of the model that runs on the CPU will be slower. For comparison, our vLLM route measured about 45 tokens/s for one lane.
- **Quality is unknown.** It isn't a bigger version of our Qwen3.8-27B. It's a different model in the same family (Qwen3.8-Flash-Next, 125B), squeezed to 2-3 bits. The repo has no coding benchmarks.
- **Two cautions.** The repo has no license file. Its installer downloads an engine binary and model files that aren't pinned to a version or hash-checked; we would build from source at a fixed commit instead.
