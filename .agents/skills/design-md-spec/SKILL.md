# design.md — visual identity spec (reference)

Vendored reference from google-labs-code/design.md (Apache-2.0). Read `spec.md` in this directory
for the full format specification and `PHILOSOPHY.md` for the intent. When building UI for this
project, author a `design.md` at the app root per the spec and treat it as the binding visual
identity contract for all agents.
