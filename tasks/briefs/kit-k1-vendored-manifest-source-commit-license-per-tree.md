## Design (pinned — build it, do not redesign it)
1. **`scripts/vendored_manifest.py`** — stdlib only. `--root .` `--write` regenerates `sandbox-kit/VENDORED-MANIFEST.md`; `--check`
   exits 1 with a named diff when the committed file differs from a fresh generation (rc 0 when equal). The set of vendored roots is
   DECLARED in the script as a frozen list (path → source repo/URL → the provenance line it comes from), derived once from
   `VENDORED-FROM.md` and pinned — a root present in the provenance table but absent from the list, or vice versa, is a named
   failure of `--check` (the table is parsed for its `Here` column; parse failures are named, never skipped).
2. **Per root, the manifest row carries:** the path; the upstream source (repo or vendor name from the provenance table); the pinned
   commit or digest — from `upstream.lock.yaml` when that tool is pinned there (cite the lock key), else `unpinned (vendored copy)`
   stated as such; the license: the SPDX id read from the tree's own license file (`LICENSE*`, `COPYING*`, `NOTICE*`) with the
   file's sha256 — `none found` stated as such, never guessed; the regular-file count; the tree digest = sha256 over the sorted
   (relative path, file sha256) pairs of every regular file, symlinks recorded by target and refused if they escape the root.
   Binary files hashed like any other. Excluded from every walk: `.git`, `__pycache__`, `*.pyc`, `node_modules` — the exclusion
   list is printed in the manifest header.
3. **The header** states: generated by which script at which commit (`git rev-parse HEAD` at generation, or `unknown` outside a
   repo), the generation time in UTC, the exclusion list, and the sentence "Regenerate with `python3 scripts/vendored_manifest.py
   --write`; `--check` is the drift gate."
4. **Agreement with the SBOM:** for every root whose source also appears in `SBOM.yaml`/`upstream.lock.yaml`, the manifest's pin
   equals the SBOM's; a disagreement is a named `--check` failure (the SBOM is S0-12's minted input — never edit it; report the
   disagreement).
5. **`tests/test_vendored_manifest.py`** — deterministic, LLM-free: (a) regenerating in a temp copy equals the committed bytes
   (the drift gate green on the tree); (b) NEGATIVE: one byte changed in one vendored file → `--check` names that root and rc 1;
   (c) NEGATIVE: a root removed from the declared list while present in the provenance table → named failure; (d) NEGATIVE: a
   symlink escaping a root → refused by name; (e) the license detection on a fixture tree with a known LICENSE file → the SPDX id
   and its sha; with none → `none found`; (f) the run is byte-identical twice (sorted walks, no timestamps inside rows — the
   header's time is the ONE line excluded from the drift comparison, stated in the test).
6. **Mutants:** the tree digest without the sorted order; the exclusion list emptied; the SBOM agreement check removed; the
   symlink refusal removed — each killed by a named test, killer lines pasted.
7. **Report discipline:** FILE IDENTITY of the FINAL bytes; every `file:line` from `grep -n` on the FINAL bytes and
   `python3 scripts/report_lint.py <report> --map M=scripts/vendored_manifest.py --map T=tests/test_vendored_manifest.py` pasted
   with MISS 0; the two `lane_gate.sh` RESULT lines (`scripts/lane_gate.sh -r be5cf35 -f "<your files>" -t
   "tests/test_vendored_manifest.py" -n 2`); `ap_screen.py` prod + `--tests` classified by run; pyflakes 0; NOT-done first-class.
