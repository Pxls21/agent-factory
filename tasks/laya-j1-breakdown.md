## Pinned decisions (with the rejected alternative)
- **Row = one incumbent decision, never a bare question.** Rejected: question-first rows (zero labels).
- **row_id = sha256(canonical JSON of {producer, question_id, state_digest, source_ref})**; `state_digest = sha256(canonical(redact(normalize(state))))`; `source_ref = {kind ∈ transcript_jsonl|lane_report|verify_report|incident_log|registry, path (repo-relative, committed), source_digest (sha256 of the file bytes at harvest), locator (JSONL message uuid | finding id + heading | the dated entry heading)}`. Rejected: a question-text hash alone (collapses legitimate repeats); path + line index alone (moves under compaction and re-landing).
- **Duplicate append is a NAMED refusal** `decision-row-duplicate: <row_id>`; the harvest counts it as a printed skip. Rejected: idempotent silent no-op (the twice-run identity test would be vacuous).
- **state = a BOUNDED, CLOSED, per-question-type extraction; never verbatim bytes.** Closed schemas in `src/agent_factory/decisions/volatile.py`; an unknown key → `decision-state-unknown-key: <question_id>.<key>`. Seven question types: `b2.hit_role` {sym, file, snippet} · `b1.finding_sev` / `b1.finding_kind` {file, kind, msg} · `d1.bug_echo_scores` {class_slug, finding_title} · `v1.finding_class` {lane, finding_id, title, paths[], disposition} · `ap.violates_row` {action_kind ∈ edit|command|brief|report, action_target (repo-relative path, or a command's leading token only), action_excerpt (≤ 400 chars, normalized, redacted), row_id (AF-AP-N), row_title} · `wf.drift` {step_id ∈ {verify-seam-first, one-increment-code-test-commit, negative-control, count-pasted, timestamp-pasted, commit-before-dispatch, impact-before-edit, premise-measured, report-lint-floor, boundary-respected}, expected, observed, drift_kind ∈ {skipped-step, out-of-boundary, substituted-step, mirror-test, prose-claim}}. Line numbers, timestamps, absolute paths, run ids and PIN SHAs are never in `state` — only in `source_ref.locator`.
- **Order of transforms: normalize → redact → canonical → sha256.** normalize = the STABILITY mechanism (enumerated volatile fields, repo-relative paths, NFC, whitespace collapse); redact = the SECURITY mechanism only (`sk-` keys, bridge tokens, bearer headers, private-key env values, `.env` contents → a fixed placeholder). Each has its own test and its own mutant; neither relies on the other. canonical = sorted keys, NFC, integers/strings only (no floats), fixed separators; one committed golden digest per type, asserted exactly, run twice bitwise.
- **Mandatory provenance per row** {producer, checkpoint_digest (the literal `none` for incumbents), question_id, calibration_state (the literal `incumbent`), incumbent_answer}; missing → `decision-row-incomplete: missing <field>` (KC-J6's mechanism). Replay verifies each row's digest; a mutated row → `decision-row-digest-mismatch: <row_id>`.
- **Harvest reads only COMMITTED sources through STRICT grammars**; unparseable → `harvest-source-unparseable: <path>:<line>`; uncommitted → `harvest-source-uncommitted: <path>`; never a silent skip. Sources (D-044, both consumers): the sandbox transcript digests + JSONL (hive-scout / hive-reviewer returns — yield 0 today, the parser still exists and is fixture-tested), the PC lane reports (`tasks/briefs/*/*-report.md`, 130), the verifier reports (45; 436 classed findings), `docs/INCIDENT-LOG.md` (82 dated entries, 56 naming a row; 116 registry rows). The harvest line: `harvest: <n> rows, <k> per question type` + `negatives: 0 (hand-labeled in J2)` per type — the KC-J7 measurement, pasted verbatim into the increment's report. Rejected: a one-time hand-labeled fixture (hides yield; not re-runnable).
- **The never-a-gate screen** `scripts/no_laya_in_gates.py`: scanned set = the explicit committed allowlist `scripts/gate_files.txt` (hooks, CI workflows by name, the lint/screen/gate/validator/runner/push scripts, `harness-ports/bin/pc-lane.sh`, every `proofs/*/check_*.py`) + a COMPLETENESS control (the structural patterns `scripts/hooks/*`, `.github/workflows/*.yml`, `proofs/*/check_*.py` walked; an unlisted match → exit 4 `gate-file-unlisted: <path>`); vocabulary = a CLOSED token list (`laya, systemone, system_one, system-one, jev, jevcache, sieve, sieve-run, decide-harvest, decide_harvest, laya-decide, agent_factory.decisions, decisions.ledger, decisions.canonical, decisions.jsonl`) on identifier boundaries, case-insensitive, plus a Python-import check for `agent_factory.decisions`; exit 0 clean, exit 3 `file:line:token` per hit, exit 64 usage; non-fires by CONSTRUCTION (only listed files are read); the negative control plants `laya` in a fixture tree's `scripts/hooks/pre-commit` (`--root`), the positive control strips it; wired into `scripts/hooks/pre-commit` with NO bypass variable (KC-J1 is an absorbing barrier).
